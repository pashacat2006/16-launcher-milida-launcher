# Millida + 16 — личная сборка

Цель: настоящее окно Millida с её каталогом, учётной записью и модом; установка обычного Minecraft, Java и запуск — кодом 16 Launcher внутри того же приложения.

## Как это устроено

- Библиотека сборок остаётся в `%APPDATA%\net.millida.launcher\profiles.json`. Существующие сборки появляются без экспорта. Новые сборки, скачанные в этом окне, попадают в ту же библиотеку.
- Миры, моды, настройки и скриншоты используются из исходной папки каждой сборки Millida. Второй копии сборки в отдельном 16 Launcher не создаётся.
- Движок 16 хранит служебные настройки и игровые файлы в `%APPDATA%\net.millida.launcher\engine16`. Отдельно установленный 16 Launcher для работы гибрида не требуется.
- Уже скачанные общие ресурсы и библиотеки Minecraft копируются из кеша Millida по мере необходимости; движок 16 проверяет их штатным способом. Моды и миры при этом не дублируются.
- Обычные загрузчики: vanilla, Fabric, Quilt, Forge и NeoForge. Сборки собственного формата Millida, нативные игры и Horizon используют исходный совместимый путь Millida.
- Двоичные загрузки каталога идут через HTTP-клиент 16, с сохранением проверки хешей, паузы и распаковки Millida. Каталог, авторизация и получение косметики по-прежнему обращаются к Millida: у 16 нет замены этим сервисам.
- Штатный мод Millida устанавливается её исходным кодом, для совместимой версии игры и загрузчика. Его отдельный сеансовый токен передаётся процессу игры в окружении. Аккаунт Millida не экспортируется в файлы аккаунтов 16.
- Доступен один процесс игры через движок 16 одновременно. Ускорение конкретной сборки нужно измерять: время загрузки самих модов и подключения к серверам от замены лаунчера не исчезает.
- Для обычного Minecraft недостающая музыка (`minecraft/sounds/music/*.ogg`) докачивается после запуска игры. Текстуры, языки, звуковые эффекты и прочие ресурсы готовятся до запуска. Большие ресурсы загружаются частями с проверкой полного SHA1; законченные части сохраняются при отмене и используются при продолжении. До окончания фоновой загрузки некоторые музыкальные композиции могут не играть.

## Запуск

После успешной сборки: `Start.cmd` или `Launcher\Millida16.exe`. Перед этим полностью выйди из оригинальной Millida через её значок в трее: обе копии используют одну библиотеку и защиту от повторного запуска. Не обновляй одну сборку одновременно в двух копиях.

Это отдельная личная копия. Её автообновление и автоматическая переустановка официальным установщиком отключены. Оригинальные установленные приложения не заменяются.

## Сборка и проверки

`pwsh -File .\Build.ps1` собирает интерфейс, проверяет его синтаксис и размер и создаёт EXE. `-CheckOnly` дополнительно проверяет Rust без создания EXE. Подготовленный локальный Rust находится в `.tools\toolchain`; Node.js и Visual Studio C++ должны быть установлены.

Исходники интерфейса и адаптера: `hybrid`. Исходники движка 16 и изменения для встраивания: `vendor\rust-launcher-main`. Логи текущей проверки — `.tools\frontend-build.log` и `.tools\backend-check.log`.

Исправление сети от 18.11.2026: неудачные предварительные HEAD-запросы больше не запрещают настоящую загрузку или использование готовых файлов. Описание уже скачанной версии Minecraft и профиль выбранного Fabric/Quilt берутся из кеша; клиентский JAR и индекс ресурсов также подхватываются из Millida. Проверены два сценария регрессии, сохранность существующей сборки и настоящий запрос к адресу Mojang из сообщения об ошибке (успешно, 1,29 с). Это проверка загрузочного кода; запуск Minecraft до меню пользователь проверяет отдельно.

Для задержки на 45% найдены 20 недостающих музыкальных ресурсов общим объёмом 274,7 МиБ. Проверены SHA1 всех 3830 обязательных ресурсов: отсутствующих и повреждённых нет. Ожидание музыки перед запуском убрано; фоновая докачка начинается после появления процесса игры. Проверки отмены, продолжения и целостности проходят вместе с остальными тестами runtime: 20 успешно. Логи: `.tools\background-tests.log`, `.tools\background-release-build.log`, `.tools\background-runtime-stderr.log`. Время выхода самой игры в меню ещё не измерено.
